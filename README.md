# TinyProof

## Docker

To start both the frontend and backend run

```
docker compose up
```

## Git

In order to get all submodules when cloning clone using the following command
```
git clone --recurse-submodules https://github.com/utmgdsc/TinyProof.git
```

If you have already cloned the repo and need to get the submodules run, 
```
git submodule update --init --recursive
```
